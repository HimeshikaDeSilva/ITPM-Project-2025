We built this web app to allow for smarter kitchen choices, which is for helping people. SmartChef suggests recipes according to existing ingredients. Furthermore, the meals are carefully planned in order to help to reduce more food waste. To the users, shopping lists can be generated, and also, ideas for what to cook, as well as the tracking of what’s in their pantry, are available. Cooking will be made easier, waste will be reduced, as well as time will be saved by this app for everyone.
